# DLH Modern AI

This repository contains practical projects completed as part of my Data Science learning journey at the Digital Learning Hub.

The projects focus on collecting, preparing, analysing, and visualising data, as well as applying supervised and unsupervised machine learning techniques.

## Projects

### 1. Data Preparation and Visualisation

📁 [`data_analysis/data_preparation_visualization`](data_analysis/data_preparation_visualization)

This project follows the main steps required to prepare a customer churn dataset for analysis and machine learning.

Main topics covered:

- Exploring the dataset and its structure
- Identifying missing values
- Converting column data types
- Cleaning invalid values
- Removing duplicate records
- Removing unnecessary identifiers
- Visualising the target variable
- Analysing categorical and numerical distributions
- Creating a correlation heatmap
- Comparing features with customer churn
- Applying Chi-Square tests
- Applying numerical statistical tests
- Creating new features
- Encoding categorical features
- Scaling numerical features
- Splitting data into training and testing sets

---

### 2. Web Scraping

📁 [`data_analysis/web_scraping`](data_analysis/web_scraping)

This project explores different ways of collecting data from websites and web-based sources.

Main topics covered:

- Fetching HTML pages
- Extracting information from HTML
- Scraping paginated websites
- Collecting data through an API
- Extracting structured JSON-LD data
- Logging into a website before scraping
- Collecting product lists
- Extracting individual product details
- Handling dynamically loaded content
- Scrolling through pages with Selenium

### 3. Tree-Based Models

📁 [`machine_learning/tree_models`](machine_learning/tree_models)

This project covers the complete workflow of building and evaluating tree-based classification models.

Main topics covered:

- Building a Decision Tree classifier
- Training the model
- Visualising a Decision Tree
- Generating predictions
- Evaluating classification performance
- Applying pre-pruning
- Exploring the cost-complexity pruning path
- Pruning a Decision Tree
- Selecting the best `ccp_alpha`
- Training a Random Forest classifier
- Analysing feature importance
- Applying boosting methods

### 4. Unsupervised Learning

📁 [`machine_learning/unsupervised_learning`](machine_learning/unsupervised_learning)

This project introduces methods used to discover patterns in data without predefined target labels.

Main topics covered:

- Standardising numerical features
- Reducing dimensions with PCA
- Grouping observations with K-Means
- Selecting the optimal number of clusters
- Applying Agglomerative Hierarchical Clustering

---

### 5. Linear Models

📁 [`machine_learning/linear_models`](machine_learning/linear_models)

This project introduces linear models for regression and classification.

Main topics covered:

- Linear Regression
- Regression evaluation metrics
- Ridge Regression
- Lasso Regression
- L1 and L2 regularisation
- Feature selection
- SHAP model explainability
- Logistic Regression
- Support Vector Machines
- Linear, polynomial, and RBF kernels
